# Biomedical Engineering Work Plan

## Scope

This team defines the clinical and standard-driven behavior that the software must implement.

## Main Documentation Files

- `docs/test-plan.md`
- `docs/software-architecture.md`
- `docs/integration-protocol.md`

## Deliverables

- Hughson-Westlake rule definition
- valid test frequencies from `250 Hz` to `8000 Hz`
- explanation of IEC 60645-1 in report language
- hearing-test procedure notes for the software teams
- criteria for validating clean pure-tone generation

## How This Team Contributes to Code

- First, document the rule.
- Then, hand the expected behavior to the software engineering team.
- Finally, review tests and edge cases against the documented clinical rule.
